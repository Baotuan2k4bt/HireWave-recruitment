HireWave – Job Portal System
Spring Boot, ReactJS, MySQL, JWT, Spring Security, WebSocket | 1 | 4 months

Designed and deployed a full-stack job portal connecting 500+ job seekers with 120+ employers, enabling end-to-end job applications and real-time communication. The system handles 200+ daily active users with 99.2% API uptime.

Key Contributions:
• Designed and implemented 18 RESTful APIs for job posting, candidate applications, and employer dashboards, reducing API response time by 42% through query optimization and caching with Redis.
• Built a role-based authentication system using Spring Security and JWT, supporting 3 user roles (Candidate, Employer, Admin) with OTP verification and secure password hashing (BCrypt).
• Developed a MySQL database schema with 12 normalized tables, improving data integrity and enabling efficient search queries that reduced job search latency from 2.1s to 0.4s.
• Integrated WebSocket for real-time messaging between candidates and employers, supporting 80+ concurrent chat sessions with message persistence and read receipts.
• Automated email notifications for application updates and OTP delivery using Spring Mail, increasing user engagement by 35% and reducing manual follow-ups by 90%.
